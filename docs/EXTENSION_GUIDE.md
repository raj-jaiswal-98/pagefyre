# Warzone Web Destroyer — Chrome Extension User & Installation Guide

This guide explains how to install, test, and use the **Warzone Web Destroyer** Chrome Extension.

---

## 🚀 Installation Instructions (Load Unpacked)

1. Open **Google Chrome**, **Microsoft Edge**, or **Brave Browser**.
2. Navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the project directory:
   ```
   f:\Desktop\projects\destroy-with-dragons
   ```
6. The extension **Warzone Web Destroyer - Monsters & Dragons** is now installed and ready!

---

## 🎮 How to Use

### 1. The Interactive Sandbox Demo
* Open `demo/index.html` or visit `http://localhost:8080/demo/index.html`.
* The **Warzone Command HUD** mounts automatically.

### 2. Destruction on Any Live Website
* Pin the extension icon 🔥 in your Chrome toolbar.
* Open any website (Wikipedia, News, Blogs, Portals).
* Click the extension icon to open the **Armed Popup**.
* Select any of the **14 Champions** and click **Deploy This Titan On Site**, or hit **Unleash the Swarm (Apocalypse)**.

---

## 🎛️ In-Page Tactical HUD Features

* **Live Stats**: Displays real-time destroyed element count, cumulative damage dealt, chaos percentage, and living monster count.
* **Hero Roster (14 Buttons)**: Click any hero icon to spawn them directly in your active viewport.
* **🎯 Strike Tool**: Turn your cursor into a crosshair and click any element on the webpage to incinerate, crush, throw, eat, or slice it.
* **🎨 Spray Tag**: Trigger the leader's signature graffiti stencil on demand.
* **✨ Restore**: Instantly rebuilds and restores the original website DOM cleanly with sound effects.
* **🔊 Audio Toggle**: Mute or unmute procedural Web Audio synthesis at any time.
